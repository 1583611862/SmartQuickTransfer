# Smart Quick Transfer（智能双击投放）

双击物品，自动投放到合适的目标位置。少拖拽、少整理，库存归位一步到位。

- 当前版本：**2.1.6**
- 依赖：无需其他 Mod

---

## 这个 Mod 能做什么

在商店里整理物品时，双击一个物品，它就会被送到合适的地方——最近用过、并且能接收它的窗口；如果这台机器有专门用途，也会优先送到那里。

从机器或工具里取出的物品会自动回到存放区；没有合适窗口时，物品会放进默认存放位置。整个过程不需要你手动寻找和拖拽。

## 主要特点

- **双击即投放**：双击窗口里的物品即可快速转移，省去反复拖拽。
- **批量框选**：拖拽框选多个物品后双击，可一次性转移全部选中物品，每个物品各自选最合适的目标。
- **动态装备轮盘**：未拖拽物品时按鼠标中键呼出，自动扫描仓库中所有符合原版 Toolbox 准入规则的装备。鼠标指向目标、左键确认即可装备，不需要打开仓库、不需要提前放进 1～9 快捷栏，也不受 9 个槽位限制。滚轮翻页，右键 / 中键 / Esc 取消。轮盘只在打开期间接管输入，拖拽物品时中键仍是原版翻转。
- **自动选对目标**：综合最近使用的窗口和物品用途来选目标，机器放不下时会自动换到下一个可用目标。
- **遵循游戏规则**：物品只会被放进游戏原本允许放入的槽位，不会强行塞进不兼容的机器。
- **取物自动归位**：从机器或工具中取出的物品直接回到存放区。
- **照顾顾客需求**：顾客想买的物品优先放到桌面，方便直接成交。
- **保留原版交互**：机器、容器以及彩票、文档、黑灯、鱼饲料等特殊物品的原有双击行为保持不变。
- **飞行动画**：转移时有一段短暂的飞行动画和落点提示，可按需关闭。
- **记住你的习惯**：如果投放位置不合适，直接把物品拖到你想放的地方，下次会自动参考这次纠正。数据只存在本机。

## 使用方法

订阅后在游戏中启用本 Mod 即可。双击窗口中可移动的物品，就会自动快速投放；拖拽框选一批物品后双击，则整批一起投放。

从 v2.0.0 起：如果你觉得投放位置不对，直接把物品拖到你想要的地方，Mod 会记住这次纠正，下次投放时参考你的习惯。所有记忆都保存在本机，不联网、无需设置。

## 兼容性与注意

- 不需要任何其他 Mod 作为前置。
- 默认不改变机器、容器和特殊物品的原版双击行为。
- 学习数据只保存在你自己的电脑本地。
